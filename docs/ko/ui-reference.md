# 팝업 UI 참고서

한국어 · [English](../ui-reference.md) · [README](../../README.ko.md)

## 메신저 열기

에이전트가 실행 중인 pane에서 **Send Prompt to Agents**를 실행합니다. 현재
에이전트가 고정 발신자가 됩니다. 선택한 pane에 에이전트가 없으면 팝업 대신 오류
알림을 표시합니다.

로컬 에이전트는 Herdr workspace 라벨 순으로 즉시 표시됩니다. 유니코드 라벨을
보존하고 worktree 기반 workspace에는 `WT:` 접두사가 붙습니다. 원격 에이전트는
SSH 호스트 별칭 아래에 묶고, 각 호스트 안에서 workspace별로 다시 묶어 표시합니다.
그룹 식별에는 Herdr의 `workspace_id`를 사용하므로 표시 이름이 같은 서로 다른
workspace도 합쳐지지 않으며, 이 경우 ID를 함께 표시해 구분합니다.

## 수신자 행

조작 상태와 에이전트 수명 주기 표시는 서로 분리돼 있습니다.

- `›`: 키보드 커서
- `[x]`: 선택된 수신자
- `●`: 작업 중
- `○`: 대기
- `✓`: 완료
- `!`: 차단
- `~`: 오래된 상태

색상은 보조 표현이므로 단색 화면에서도 상태를 구분할 수 있습니다. workspace
이름은 각 그룹 제목에 한 번만 표시하고 에이전트 행에서는 반복하지 않습니다.
각 행은 Agent Labels 이름, Herdr pane ID, 수명 주기 상태를 우선 표시합니다.
전체 session ID와 workspace 정보는 주 화면 너비를 차지하지 않으면서 검색할 수
있습니다. 호스트 제목은 에이전트 수를 항상 `(n)`으로 표시하고, workspace 제목은
에이전트가 여러 개일 때만 같은 형식의 개수를 표시합니다.

긴 그룹은 스크롤 중에도 호스트와 workspace 제목을 유지합니다. 작은 화면에서
sticky 제목을 하나만 표시할 수 있으면 더 구체적인 workspace 제목을 우선합니다.
필요한 경우 수신자 제목에 현재 보이는 범위를 표시합니다. 접속할 수 없는 원격
호스트는 요약해서 보여주며 상세 화면에서 각 별칭과 최근 오류를 확인할 수 있습니다.

## 메시지 편집기와 레이아웃

팝업은 큰 터미널에서 최대 120열×32행까지 확장되고 작은 터미널에 맞춰 축소됩니다.
탐색된 수신자 목록에 대부분의 공간을 할당하면서 가능하면 soft-wrap된 메시지
4행 이상을 유지합니다. 긴 메시지는 텍스트 커서를 따라가며 viewport scrollbar를
표시합니다.

좁은 터미널에서는 단축키 도움말을 자르지 않고 다음 줄로 넘깁니다. 팝업은 Herdr
터미널 팔레트를 상속하며 수명 주기 색상은 작업 중, 완료, 차단, 경고 상태에만
사용합니다.

UI 언어는 `LC_ALL`, `LC_MESSAGES`, `LANG` 순으로 결정하며 영어, 일본어,
한국어를 지원합니다. 지원하지 않는 locale은 영어를 사용합니다.

## 키보드 조작

- `Up` / `Down`: 선택지, 수신자 또는 메시지 행 이동
- `Enter`: 강조된 탐색 방식 확정
- `D` / `L`: 원격 탐색 또는 로컬 전용 선택
- `C` / `D`: 코디네이터 위임 또는 직접 전송 선택
- `Space`: 수신자 선택 전환
- `Ctrl+A`: 필터된 수신자 모두 선택
- `Ctrl+D`: 선택 해제
- `Tab`: 수신자 목록과 메시지 편집기 전환
- `Ctrl+O`: 전송 방식 화면 다시 열기
- `Ctrl+R`: 로컬 및 허용된 원격 에이전트 새로고침
- `Ctrl+U`: 접속 불가 원격 호스트와 최근 오류 표시
- `Ctrl+G`: HAM 스킬 설치기와 가이드 열기
- `Ctrl+S`: 프롬프트 전송
- `Esc`: 이전 화면으로 이동하고 탐색·전송을 취소한 뒤 팝업 닫기
